# The BeerBrother 🍺

> **Este proyecto está archivado.** Ya no se encuentra operando en [thebeerbrother.cl](https://thebeerbrother.cl), pero durante varios años fue un espacio vivo de recomendaciones de cine y series. Lo dejo aquí como recuerdo de ese tiempo.

---

Por varios años, **The BeerBrother** fue el lugar donde escribí con entusiasmo sobre películas y series — con sus altos y bajos, sus temporadas de mucho contenido y sus silencios, sus buenas recomendaciones y quizás alguna que no envejeció tan bien. Fue un proyecto personal que me dio mucho y al que le dediqué genuinas ganas.

**thebeerbrother.cl** ya no está en línea, pero el código y el contenido permanecen aquí como testimonio de ese trabajo.

Gracias a quienes alguna vez lo leyeron. 🎬🍺

---

## 🚀 Tecnologías

- **Astro 7.x**: Framework web para una performance rápida.
- **Bulma**: Framework CSS utilizado para el diseño.
- **Content Collections**: Gestión de posts con validación de esquemas.
- **Schema.org**: Datos estructurados para mejor SEO.

## 🛠️ Comandos

Todos los comandos se ejecutan desde la raíz del proyecto:

| Comando        | Acción                                                |
| :------------- | :---------------------------------------------------- |
| `pnpm install` | Instala las dependencias necesarias.                  |
| `pnpm dev`     | Inicia el servidor de desarrollo en `localhost:4321`. |
| `pnpm build`   | Genera el sitio estático en la carpeta `./dist/`.     |
| `pnpm preview` | Previsualiza el build de producción localmente.       |

## 📁 Estructura del Proyecto

- `src/content/blog/`: Contiene todos los artículos en formato Markdown.
- `src/layouts/`: Plantillas para las páginas y posts.
- `src/components/`: Componentes reutilizables como la tarjeta de post.
- `public/`: Assets estáticos (imágenes de banners, autores, favicon, etc.).
